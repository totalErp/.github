# schedulazioni

## Riepilogo

- Repo: .github

## Contenuto

| Nome | Orario | Note |
|-----|-----|-----|
| Aggiornamento Articoli Contropartita | Ogni 5 minuti | Viene eseguito il batch **run_update_artico.bat** che lancia la query `C:\SqlJobs\job_update_artico.sql`. Questa avvia la stored procedure **usp_UpdateArtico_Controp_ME** che aggiorna la controparte delle vendite negli articoli a 5005 quando la variante 3 contiene `.ME` o `.MM`. |
| Aggiornamento Stato Intercompany | 22:00 | Viene eseguito il batch **job_aggiorna_stato_testmag_modulo_intercompany.bat** che lancia la query `C:\SqlJobs\job_aggiorna_stato_testmag_modulo_intercompany.sql`. Questa avvia la stored procedure **usp_AggiornaStato_Testmag_modulo_Intercompany** che imposta in **TESTMAG** il campo `tm_iystato = 'A'` per i DDT emessi intestati al fornitore **ARSIOFIL**. |
| Pareggio Magazzino OdP / DDT | 22:30 | Viene eseguito il batch **job_allinea_quantita_cdp_ddt.bat** che lancia la query `C:\SqlJobs\job_allinea_quantita_cdp_ddt.sql`. Questa avvia la stored procedure **usp_AllineaQuantita_CDP_DDT** che pareggia le quantità degli articoli nei **Carichi di Produzione** quando differiscono dalle quantità presenti nel DDT emesso. Serve per correggere differenze dovute al **peso condizionato**. |
| Replica Dati Intercompany | 22:45 | Lancio del programma intercompany **Replica Dati**. |
| Replica Documenti Intercompany | 23:15 | Lancio del programma intercompany **Replica Documenti**. |
| Ricostruzione Progressivi Magazzino | 23:30 | Lancio del programma **ricostruzione progressivi** di magazzino **BNMGRCAP**. |
| Esportazione OdP MTB → ARS | 23:45 | Viene eseguito il batch **job_esporta_odp.bat** che lancia la query `C:\SqlJobs\job_esporta_odp.sql`. Questa avvia la stored procedure **usp_EsportaOdp_MTB_To_Arsiofil** che trasporta gli **OdP di MTB intestati ad ARS** nell'ambiente ARS creando **OdP e IM intestati a MTB**. |
